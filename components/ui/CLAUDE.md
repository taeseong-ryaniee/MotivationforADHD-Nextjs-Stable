# components/ui/CLAUDE.md

Scope: this directory only.

- Generated by shadcn/ui (`components.json`: style "default", baseColor
  "neutral", cssVariables, Tailwind v4). Add new primitives with
  `bunx shadcn@latest add <component>` rather than hand-rolling one the
  registry already provides.
- `loading-spinner.tsx` is a hand-written exception — there's no matching
  registry item, so `shadcn add loading-spinner` won't touch it; edit it
  directly.
- These are the primitives DESIGN.md's tokens (font/color/spacing) apply to —
  see root `CLAUDE.md`'s Design System note before changing anything visual
  here.
